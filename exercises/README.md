# Ikasle-fitxak — AA bidezko garapena OpenCode-rekin

Fitxa hauek `ticketak-api` starter repoarekin erabiltzeko dira. Bakoitza independentea da, baina saioen ordena jarraitzea gomendatzen da.

## Nola erabili

1. Irakurri fitxaren **helburua** eta **onarpen-checklista**.
2. Egin urratsak bikoteka; txandakatu *gidaria* eta *nabigatzailea*.
3. Amaitzean, egiaztatu checklista eta entregatu fitxan adierazitakoa.

## Saioen mapa

| Saioa | Fitxa | Gaia | Denbora |
|---|---|---|---|
| 2 | [E2](e2/FITXA.md) | Aluzinazio-detektibea | 30 min |
| 4 | [E4](e4/FITXA.md) | AAk sortutako PR baten review-a | 45 min |
| 5 | [E6](e6/FITXA.md) | Agenteak: anatomia eta kontrola | 85 min |

## Materiala

- `ticketak-api` repo-a, `.venv` ingurunearekin.
- OpenCode instalatuta eta konfiguratuta.
- `AGENTS.md` eta `README.md` irakurrita.

## Saio aurretik — sandboxa

- [ ] Container, VM edo Windows Sandbox batean nabil.
- [ ] Repo bakarra dago mountatuta; ez nire home osoa.
- [ ] Ez dago sekretu errealik, SSH gakorik edo tokenik.
- [ ] Sarea behar den gutxienekoa da.
- [ ] `git status` eta `git diff` egiaztatzen ditut.
- [ ] Reset egiteko modua dut.

## Arau nagusiak

- **Egiaztatu, ez fidatu:** probek, dokumentazioak eta irakurketak berresten dute.
- **Ez kopiatu itsu:** ulertu kodea eta azaldu hitzez hitz.
- **Ez erabili datu errealik:** dena sintetikoa da.
- **Ez commit-atu sekreturik.**
- **Diff txikia:** aldaketa bat, helburu bat.
