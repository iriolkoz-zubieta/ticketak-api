## Helburua

AAk **ziurtasunez** asmatzen duenean detektatzea. Erantzun sinesgarri bat ez da froga bat: dokumentazioa eta exekuzioa dira froga.

## Testuingurua

AAk API, metodo edo liburutegi bat asma dezake. Asmakizun horiek oso sinesgarriak dirudite, eta kodea idazten baduzu, erroreak agertzen dira. Zure lana da gezurra aurkitzea.

## 1. urratsa — Galdera bat aukeratu

Aukeratu API edo metodo **faltsu** bat. Adibideak:

- "Nola erabiltzen da Python 3.12ko `list.groupby` metodoa?"
- "Erakutsi `pandas.fast_apply` funtzioaren adibidea."
- "Zein da `requests` liburutegiko `Response.parse_json()` metodoa?"
- "Nola erabiltzen da `fastapi.Response.json_body()` metodoa?"

> **Garrantzitsua:** ez galdetu AIari ea erantzuna egia den. Hori ez da egiaztapena.

## 2. urratsa — Erantzuna jaso eta gorde

Idatzi:

- Zein prompt erabili duzun.
- Zer erantzun duen (labur).
- Zergatik dirudien sinesgarria.
- Zein urrats emango zenukeen kodea probatzeko.

## 3. urratsa — Egiaztatu

Egiaztatu **iturri ofizialetan**:

- Python dokumentazio ofiziala.
- Liburutegiaren dokumentazioa.
- Kodea exekutatzea (`python -c "..."`).
- `pip show` edo bertsioaren egiaztapena.

## 5. urratsa — Bikoteka trukatu

Bikotekideak beste alucinazio bat bilatuko du. Zuk harena egiaztatuko duzu. Ez konfiantza erantzunean; konfiantza iturrian.

## Onarpen-checklista

- [ ] Gutxienez alucinazio bat dokumentatuta.
